# logistic-regression-numpy-implementation

This project implements logistic regression using NumPy and applies it to a real dataset.

The goal was to understand how the model works internally.

## What’s included

* binary cross-entropy loss
* analytical gradient
* numerical gradient check
* gradient descent training

## Dataset

Breast Cancer Wisconsin dataset (via scikit-learn)

## Results

The model converges during training and reaches ~98% accuracy on the test set.

## Notes

The implementation was based on coursework and extended into a full workflow:
data preparation → model implementation → training → evaluation → visualization.
